# gpt_x-_deepl_Chatapp

大学で積極的な活用が推進されている ChatGPT を用い、会話履歴の長期保存（半永久的な保存）を簡単に実現する Python プログラムです。

大学側で提供されているアプリでは 1 セッションが数分で切れてしまう課題があったため、会話内容を JSON ファイル形式で出力し、後からでも続きからやり取りを再開できるようにしました。  
また、OpenAI API では消費トークン数に上限・コストがあるため、DeepL API を併用して自動翻訳を行わせることで、実質的にやり取りできる情報量を増やせるよう工夫しています。

## 事前準備・実行方法

使用する際は原則として、あらかじめ `api_keys` ファイルに各種 API キーを入力し、ファイル名を `api_keys.py` に変更した上でメインファイルを実行することをおすすめします。

* **OpenAI API:** 大学提供の API キーがある場合はそちらを、ない場合は個人でアカウントを作成し API キーを取得してください。
* **DeepL API:** 同様にアカウントを作成し、API キーを取得してください。

## 主な特徴

* **フレキシブルな入力:** 1 行入力・複数行入力のどちらにも対応
* **トークン数の節約:** DeepL による自動翻訳で OpenAI API の消費トークン数を削減
* **会話履歴の保存と再開:** JSON 形式で会話を保存し、次回以降もスムーズに続きから再開可能
* **raw モード（自動翻訳オフ）の搭載:** コード送信時など、翻訳を挟みたくない場合にも対応
* **柔軟な API キー管理:** 設定ファイルからの自動読み込みのほか、起動後の変更・設定にも対応
* **テキスト出力:** 会話内容をテキストファイル形式（日本語 / 英語）でエクスポート可能
* **再翻訳機能:** 保存された過去の会話内容をコマンド 1 つで再翻訳

## コマンド一覧

`help` コマンドを実行することで、以下の対応コマンド一覧を出力できます。

| コマンド | 説明 |
| :--- | :--- |
| `one` | 1 行のみ入力 |
| `mult` | 複数行の連続入力 |
| `save` | プロンプト（会話履歴）をエクスポートして終了 |
| `new` | 会話を新規リセットしてやり直す |
| `info` | 現在のトークン数を表示（インポート直後は無効） |
| `view` | 会話内容を全表示 |
| `translate` | 会話内容を日本語化して表示 |
| `exit` | 保存せずに終了 |
| `reload` | アプリを再起動 |
| `settings` | 詳細設定を表示 |
| `print` | テキストファイル形式で会話内容を出力 |

---

## raw モードについて（settings → 1）

ChatGPT におけるトークン消費量を抑えるため、本プログラムは送信・受信時に自動翻訳を挟む設計になっています。  
しかし、プログラムのソースコードを送信する場合や、自動翻訳によって意図しない回答が生成されてしまう場合、この機能がデメリットとなることがあります。

通常は自動翻訳を有効（raw モード：オフ）にしておくことを推奨しますが、上記のようなケースでは raw モードを有効化（自動翻訳をオフ）にしてご使用ください。

## 初期プロンプトの設定と翻訳処理について

近年、単なる質問にとどまらず様々な用途で GPT が活用されている流れに対応するため、GPT に渡す**初期プロンプト（システムプロンプト）を変更できる機能**を追加しました。

標準設定では英語でプロンプトが渡される仕様のため、日本語で入力した場合は翻訳処理が必要となります。そのため、プロンプト指定後に「日本語で入力したかどうか」をユーザーに確認し、翻訳処理の有無を切り替える仕様にしています。（※将来的に自動判定化を目指していますが、現状は対話形式で指定する仕様となっています。）
